File to naviage scripts during for C. neoformans pangenome creation and analysis by CER.

1. Get Fastq files 
	a. For genomes: fastq.py 
	b. For RNA-seq reads: fastq-funannotateRNA.py 
2. Assembly 
	a. aaftf_batch.py 
3. Assess nucleotide assembly with BUSCO 
	a. busco.py 
4. Annotation 
	a. fun_batch.py 
5. Ortholog formation 
	a. Get diamond commands: orthofinder.py 
	b. Run diamond runs: diamond.py 
	c. Analyze diamond runs: finish.py 
6. Ortholog analysis 
	a. Removing bad orthologs 
		i. Map reads with bwa: findfakes.py 
		ii. Finish and get all bad orthologs with: readmap_finish.py 
	b. Classify orthologs as core/accessory/singleton: classify.py 
7. Detailed analysis 
	a. Find proteins of nanopore strains in Orthofinder_sequence output with: search.py 
		i. Run blast of Funannotate predicted proteins against nanopore reads to find locations with: tblastn.py 
	b. Get the open/closed curve sampling with: new_genome_sample.py 
		i. Calls orthologs as core/accessory/singleton as it adds new genomes randomly 
	c. Randomly sample amount of already called core/accessory/singleton gene families with: rando_sample.py 
		i. Uses information of core/accessory/singleton genes based on final amount of genomes in each ortholog 
	d. Get the protein length of reference proteins and the orthogroup they are associated with: prot_length.py 
	e. Get the annotations from the reference genome with: geneannot.py \
	f. Get annotations for the longest sequence in each orthogroup with: longest_sequence.py 
		i. Attach annotations to each orthogroup with: annotations.py 
	g. Compare the ortholog presence of different subsets of the genomes 
		i. a and alpha mating type: aalpha.py 
		ii. clinical and environmental isolation source: clin_env.py 
	h.Get GOterm analysis with: getgo.py
